PROYECTO FARMA — OBJETIVOS Y REQUERIMIENTOS
===========================================
Proyecto académico con Django + Django REST Framework + SQLite.
Entorno local de desarrollo (sin requisitos de producción).

1. BASE DE DATOS (SQLite)
-------------------------
[ ] Usar SQLite como motor de base de datos local (db.sqlite3).
[ ] Crear la tabla MEDICO con id (PK autoincremental) y nombre (TEXT NOT NULL).
[ ] Crear la tabla PACIENTE con id (PK autoincremental) y nombre (TEXT NOT NULL).
[ ] Crear la tabla MEDICAMENTO con id (PK autoincremental), nombre (TEXT), tipo (TEXT) y gramos (REAL NOT NULL).
[ ] Crear la tabla SEDES con id (PK autoincremental), nombre (TEXT NOT NULL UNIQUE) y direccion (TEXT NOT NULL).
[ ] Crear la tabla RECETA con id (PK autoincremental), medico_id (FK a MEDICO), paciente_id (FK a PACIENTE) y fecha (TEXT NOT NULL).
[ ] Crear la tabla RECETA_MEDICAMENTO con id (PK autoincremental), receta_id (FK a RECETA), medicamento_id (FK a MEDICAMENTO) y cantidad (INTEGER NOT NULL).
[ ] Crear la tabla ALMACEN con id (PK autoincremental), sede_id (FK a SEDES), medicamento_id (FK a MEDICAMENTO) y cajas (INTEGER NOT NULL).
[ ] Respetar los nombres exactos de las tablas usando Meta.db_table.
[ ] Respetar los tipos de columna del esquema (TEXT, REAL, INTEGER, PK INTEGER AUTOINCREMENT).
[ ] Generar y aplicar las migraciones de Django.
